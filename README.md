# Для одной очень красивой девушки по имени Ульяна

Небольшая интерактивная сцена-промпт: конверт, который открывается, письмо, четыре мысли и тихий финал.
Полностью статический сайт: **HTML + CSS + vanilla JavaScript**, без сборки, бэкенда и зависимостей.

```
index.html      разметка четырёх экранов
styles.css      визуальный фундамент, адаптив, дым, reduced-motion
script.js       навигация по сценам, конверт, отказ от чтения, слайдер
render.yaml     конфигурация деплоя на Render
```

## Как запустить локально

Откройте `index.html` в браузере — сборка не нужна.

## Деплой на Render

Render раздаёт статику через глобальный CDN с бесплатным TLS.

**Шаг 1. Запушьте файлы в Git-репозиторий** (GitHub или GitLab). В репозитории должны лежать
`index.html`, `styles.css`, `script.js` и `render.yaml` — все в корне.

**Шаг 2. Создайте Static Site** в [Render Dashboard](https://dashboard.render.com/):
*New → Static Site* → подключите репозиторий.

Если репозиторий содержит `render.yaml`, Render подхватит настройки сам. Иначе укажите вручную:

| Поле | Значение |
| --- | --- |
| Build Command | `exit 0` |
| Publish Directory | `./` |
| Environment | `SKIP_INSTALL_DEPS` = `true` |

Через пару минут сайт будет доступен по адресу вида `https://uliana-letter.onrender.com`.

Каждый `git push` в ветку `main` пересобирает сайт автоматически.

Свои заголовки безопасности и политику кеширования можно задать в `render.yaml` (раздел `headers`).

## Сцены

| Экран | Что происходит |
| --- | --- |
| `intro` | запечатанный конверт с восковой печатью, кнопки «Открыть письмо» и «Не хочу читать» |
| `letter` | тёмная «бумажная» карточка с письмом |
| `cards` | четыре мысли: свайп, стрелки и точки |
| `final` | тихий финал и кнопка «Прочитать ещё раз» |

## Что можно легко персонализировать

**Текст** — весь в `index.html`:
- имя в письме: `<h2 class="letter__greeting">Ульяна,</h2>`;
- четыре мысли: блоки `.slide` внутри `.slider__track` (добавить пятую — просто скопируйте `<li class="slide">`, точки построятся автоматически);
- финальная подпись: `.signature`.

**Фраза отказа** — одна строка в `script.js`:

```js
var REFUSE_TEXT = "Так не пойдёт.";
```

Кнопка «Не хочу читать» не убегает: по нажатию под кнопкой появляется эта фраза (она же озвучивается скринридером через `aria-live`). Чтобы фраза менялась, достаточно поменять значение `REFUSE_TEXT`.

**Печать на конверте** — буква `U` в `index.html`: `<div class="envelope__seal">U</div>`.

**Цвета** — переменные в начале `styles.css` (`--bg`, `--deep-red`, `--burgundy`, `--accent`, `--accent-bright`, `--text`, `--muted`).

**Настройка под другого человека** (например, поменять цвет) — три строки в `:root`, остальное подстроится само.

## Технические заметки

- mobile-first: базовая ширина 390×844, safe-area, крупные touch-таргеты, отсутствие горизонтального скролла;
- анимации только `transform` / `opacity`, дым сделан мягкими radial-градиентами без тяжёлых картинок и без `filter: blur` по всему экрану;
- свайп карточек — нативный `scroll-snap`, поэтому он не тормозит и не конфликтует с вертикальным скроллом;
- скрытые экраны отключены от взаимодействия (`hidden` + `inert`), у кнопок есть `aria-label`, работает клавиатура (Enter/Пробел, стрелки);
- `prefers-reduced-motion` отключает дрейф дыма, покачивание конверта и сокращает переходы;
- без JS сайт не ломается: виден первый экран, остальные экраны скрыты атрибутом `hidden`.
